# Meeting minutes

The official minutes go to the **Team Minutes forum** of the Campus Virtual (only the team and
the lecturer can see it). We keep a copy here, one file per meeting
(`YYYY-MM-DD-meeting-NN.md`), so that the decisions are also versioned with the project.

The teamwork rubric (5% of the grade) rewards:

- Using Git.
- **Various** meetings, not a few massive ones.
- An **agenda published before** each meeting.
- Detailed minutes: participants, start and end time, agenda, agreements, date of the next
  meeting and a list of tasks **for each member**. Short sentences (one or two lines).

Workflow for every meeting:

1. The secretary posts the agenda in the forum at least one day before (`AGENDA.md`).
2. During the meeting, the secretary fills `TEMPLATE.md`.
3. Right after, the minutes are posted as a reply in the same forum thread and committed here.
4. Each task in the minutes becomes a GitHub issue assigned to its owner.
